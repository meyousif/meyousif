## 🚀 Featured Project:

### Automated Bubble Sheet & Essay Evaluation System

An AI-powered examination evaluation system designed to automate objective and subjective assessment workflows.

🔹 OMR-based bubble sheet evaluation
🔹 OCR-based text extraction
🔹 CNN-based folded sheet detection
🔹 YOLO-based dynamic region detection
🔹 Gemini API-based essay evaluation
🔹 SQLite database management
🔹 Excel/CSV result generation

**Tech Used:** Python, OpenCV, YOLO, CNN, OCR, Gemini API, SQLite
